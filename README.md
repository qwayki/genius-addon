# Genius Info

Аддон для [PulseSync](https://github.com/PulseSync-LLC/PulseSync-client) — подтягивает данные с [Genius](https://genius.com) прямо в интерфейс Яндекс Музыки.

## Возможности

- **Биография артиста** — блок в модалке «Об артисте»
- **Описание трека** — блок в модалке трека
- **Описание альбома** — блок на странице альбома
- **Текст песни с Genius** — как замена или fallback для текстов Яндекс Музыки (если текста нет или он битый)

Все блоки появляются автоматически при открытии соответствующей страницы/модалки — ничего нажимать не нужно.

---

## Быстрый старт

**Дважды кликни нужный батник:**

| Файл | Что делает |
|---|---|
| `build.bat` | Устанавливает зависимости, собирает, копирует в PulseSync |
| `dev.bat` | То же, но следит за изменениями и пересобирает при сохранении |

Или вручную через терминал:
```bash
yarn          # установить зависимости (один раз)
yarn dev      # dev-режим с watch
yarn build:sync  # финальная сборка
```

## Настройка токена

1. Зайди на [genius.com/api-clients](https://genius.com/api-clients)
2. Создай приложение (название и callback — любые)
3. Скопируй **Client Access Token**
4. В PulseSync → аддоны → **Genius Info** → вставь токен в настройках

Без токена блоки на страницах не появятся — вместо них покажется подсказка настроить токен.

---

## Настройки аддона

| Раздел | Настройка | Что делает |
|---|---|---|
| Genius API | Genius API Token | токен клиента с genius.com/api-clients |
| Текст песни | Источник текста | Яндекс Музыка / ЯМ + Genius (fallback) / всегда Genius |
| Страница артиста | Показывать биографию | вкл/выкл блок биографии |
| Страница артиста | Макс. длина биографии | обрезка текста, 0 = без обрезки |
| Страница трека | Показывать описание трека | вкл/выкл блок описания |
| Страница трека | Макс. длина описания трека | обрезка текста, 0 = без обрезки |
| Страница альбома | Показывать описание альбома | вкл/выкл блок описания |
| Разработка | Режим разработчика | логи в консоли + доп. отладка |

## Структура проекта

```
src/
  main.ts          точка входа: инициализация стилей, mount(), dev-режим
  mount.ts         observer-ы для страниц ЯМ (артист / трек / альбом)
  pulsesync.ts     хелперы над window.pulsesyncApi (чтение настроек)
  logger.ts        условный console.log под флагом dev-режима
  global.d.ts      типы window.pulsesyncApi для TS
  genius/
    api.ts         Genius API + кеш (Node.js https, без CORS)
    ui.ts          рендер блоков/скелетонов в DOM
    styles.ts      инжект CSS в страницу
    lyrics.ts      логика источника текста песни (ЯМ / Genius / fallback)
addon/
  handleEvents.json  схема настроек, которую показывает PulseSync
  README.md          описание аддона для стора PulseSync (не для разработки)
scripts/
  dev-build.mjs    watch-сборка → папка аддонов PulseSync
  post-build.mjs   финальная сборка → dist/
  sync-addon.mjs   копирование dist → папка аддонов
```
