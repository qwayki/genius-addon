# Genius Info

Интеграция Genius в Яндекс Музыку.

## Возможности

- 📖 Описания песен и исполнителей из Genius.
- 🎵 Полные тексты песен.
- 🛟 Автоматическая замена отсутствующих или повреждённых текстов Яндекс Музыки.
- 🎨 Нативная интеграция в интерфейс Яндекс Музыки.
- ⚙️ Настраиваемый режим отображения текста.

## Настройка

Для работы аддона требуется **Genius Client Access Token**.

Получить его можно бесплатно:

1. Перейдите на https://genius.com/api-clients
2. Войдите в аккаунт Genius.
3. Создайте API Client.
4. Скопируйте **Client Access Token**.
5. Вставьте его в настройки Genius Info.

> Токен используется только для выполнения запросов к API Genius.
